# 高性能计算相关项目

" 本项目是探究高性能计算对于大语言模型的优化过程，主要流程是探究我们通过优化和增速计算，对qwen/qwen3 0.6B这一轻量模型部署在本地电脑上的进一步使用速度和性能的优化"

## 本地电脑情况
	本地电脑使用的是联想拯救者y7000p 2024 ，显卡使用的是 nvidia 4060 laptop ， 开发环境为ubuntu 
## 1.项目开始阶段
	首先我们将轻量大模型进行了本地导入和初步使用，向其询问了相关问题，并产生回答，对大模型的初步使用达到了预期标准，确认大模型目前处于可用状态并且能在后续项目中进行使用
	其次我们进行了bachmark的设计和运行，通过统计未优化状态下的benchmark情况，我们设计了相关脚本——benchmark_fp16.py来进行基线的确定和后续工作，并且得到了benchmark_results.csv进行基线确定，该确定值较为稳定，符合大模型使用的初步预判和立项效果
